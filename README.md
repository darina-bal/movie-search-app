# Movie Search

Веб-приложение для поиска фильмов и сериалов по названию. Данные берутся из открытой базы [OMDb API](https://www.omdbapi.com/). Проект написан на HTML, CSS и JavaScript с jQuery и не требует сборки и собственного сервера: достаточно открыть страницу в браузере.

## Возможности

- Поиск фильмов и сериалов по названию.
- Список результатов: постер, название, год выхода и тип (`movie`, `series` и т. д.).
- Отдельная страница фильма: постер, год, возрастной рейтинг, дата выхода, продолжительность, жанр, режиссёр, сценаристы, актёры и описание сюжета.
- Картинка-заглушка, если у фильма нет постера или он не загрузился.
- Обработка ошибок: если ничего не найдено, выводится сообщение «Фильмы не найдены», а при проблемах с сетью или сервером появляется всплывающее окно с описанием ошибки.

## Технологии

- HTML, CSS
- JavaScript
- [jQuery 3.7.1](https://jquery.com/) — AJAX-запросы и работа с DOM (библиотека лежит в проекте, CDN не нужен)
- [OMDb API](https://www.omdbapi.com/) — данные о фильмах
- Шрифт [Inter](https://fonts.google.com/specimen/Inter) из Google Fonts

## Запуск

Устанавливать ничего не нужно.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/darina-bal/movie-search-app.git
   cd movie-search-app
   ```

2. Откройте `index.html` в браузере. Подойдёт и локальный сервер, например расширение Live Server в VS Code.

Нужен доступ в интернет: данные о фильмах и шрифт загружаются из сети.

## Как пользоваться

1. Введите название фильма на английском, например `Batman` или `Interstellar`. По русским названиям база OMDb фильмы не находит.
2. Нажмите «Найти» — появится список результатов.
3. Нажмите на фильм, чтобы открыть его страницу.
4. Ссылка «Назад к поиску» возвращает на главную.

## API-ключ

Для запросов к OMDb нужен ключ. В проекте он уже указан, поэтому приложение работает без дополнительной настройки. Чтобы подключить свой ключ:

1. Получите бесплатный ключ на [omdbapi.com/apikey.aspx](https://www.omdbapi.com/apikey.aspx).
2. Замените значение параметра `apikey` в адресе запроса в файлах `assets/scripts/main.js` и `assets/scripts/movie_page.js`.

У бесплатного ключа есть дневной лимит запросов.

## Как это устроено

1. `main.js` при отправке формы запрашивает у OMDb список фильмов (параметр `s` — поиск по названию) и выводит карточки результатов.
2. Каждая карточка — ссылка вида `movie_page.html?imdbID=<id>`.
3. `movie_page.js` берёт `imdbID` из адреса страницы, запрашивает подробности о фильме (параметр `i`) и выводит его карточку.
